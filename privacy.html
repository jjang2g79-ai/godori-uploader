Privacy Policy

Last updated: October 29, 2026

Who uses the tool

Godori Uploader is a personal desktop tool. It is used only by its owner, with the owner's own TikTok account.

What data it receives from TikTok

  • Through Login Kit (user.info.basic): the account's open ID, nickname and avatar, shown on the posting page so the owner can see which account a video will be posted to.
  • Through the Content Posting API: the creator settings needed to post (allowed privacy options, whether comments, duets and stitches are allowed, maximum video length) and the status of each post.
  • An access token and refresh token issued by TikTok.

How it is stored and used

All of this stays on the owner's own computer. The tool has no server and no database. Tokens are kept in a local file and are used only to call TikTok's API on the owner's behalf. Nothing is sold or shared with third parties, and nothing is used for advertising or analytics.

Deleting data

Access can be removed at any time in the TikTok app (Settings and privacy → Security → Manage app permissions). Deleting the local token file removes all stored data.

Children

The tool is not directed at children under 13 and does not collect data from them.

Changes

Changes to this policy will be posted on this page with a new date. Questions can be sent through the contact page of the blog.
